# Example app

An inbox on top of the component: `convex/` is the backend, `src/` the React
app. Its layout follows shadcn/ui's
[mail example](https://v3.shadcn.com/examples/mail), built from the shadcn
components in `src/components/ui`. See "Example" in the root README to set it
up, then run `pnpm dev` and `pnpm dev:example` from the root of the repo.
